# Nainital Yatra — Website & Pro SEO Pack (nainitalyatra.in)

## Is ZIP ke andar kaun-kaun si files hain:
1. `index.html` — Premium photo-rich homepage + Live Taxi Fare Estimator + 2026 JSON-LD SEO Schema
2. `kathgodam-to-nainital-taxi.html` — Dedicated SEO landing page (Kathgodam to Nainital Taxi)
3. `kainchi-dham-taxi.html` — Dedicated SEO landing page (Kainchi Dham Darshan Taxi)
4. `kumaon-circuit-tour.html` — Dedicated SEO landing page (Full Kumaon Circuit Tour)
5. `404.html` — Branded error page with WhatsApp rescue button
6. `robots.txt` — Google, Bing & AI Search (GPTBot, ClaudeBot, PerplexityBot) crawler rules
7. `sitemap.xml` — Clean XML Sitemap for Google Search Console & Bing Webmaster Tools
8. `CNAME` — Locks `nainitalyatra.in` automatically on GitHub Pages
9. `dns-cloudflare.txt` — Cloudflare DNS Import file (GitHub repo mein upload mat karna, sirf Cloudflare DNS mein import ke liye)

## Step-by-Step Upload (GitHub):
1. Is ZIP ko unzip karo.
2. `dns-cloudflare.txt` ko chhod kar baaki saari files (`index.html`, 3 route `.html` files, `404.html`, `robots.txt`, `sitemap.xml`, `CNAME`) apni `Nainitalyatra-` GitHub repo mein upload kar ke Commit kar do.
